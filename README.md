\# ReserveSync



Sistema de gestión de reservaciones para restaurantes.



\## Componentes



\- Aplicación de escritorio JavaFX.

\- Base de datos local SQLite.

\- Página web pública React.

\- Backend Java Spring Boot.

\- Base de datos central PostgreSQL.



\## Objetivo



Permitir la gestión de reservaciones desde la web y

la aplicación de escritorio, incluyendo operación offline

y sincronización de datos.
